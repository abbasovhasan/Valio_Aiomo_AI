# A4TB · Valio Aimo — project status

14 November 2026, Europe/Helsinki. Open **[A4TB · Valio Aimo](https://a4tb-valio-aimo.cozyhawthorn4.chatgpt.site)**. Public Sites HTTPS proxies the React/FastAPI application on Modal. Source, catalog and credentials remain private. All orders are simulated.

## Delivered

- **Smart order:** persistent multi-product conversation, actual catalog retrieval, grounded semantic query proposals, dietary/origin/brand constraints, precise package conversion and surplus, customer choices, budgets and delivery dates. Prices, permissions and commitments remain deterministic.
- **Products:** complete multilingual/partial-name, SKU, brand and category search, pagination and filters, package quantities, nullable live prices and direct add/replace actions. Smart order retains a bounded 16-candidate recommendation set; prepared or related replacements require explicit choice. Quotation failure preserves eligible selections as drafts.
- **Preferences:** mandatory dietary restrictions and custom exclusions affect search, alternatives, meal planning and cart validation. Explicit absence evidence is retained; contains/trace contradictions and unknown claims block compliance. Request restrictions and saved defaults have separate provenance, so clearing a saved-only restriction takes effect after re-quotation while explicit rules remain. Brand/origin/organic/priority defaults remain soft.
- **History:** scoped persistent requests with open, fresh reuse, archive/restore and personal removal; immutable receipts, spending and audit records remain. Reuse clears approval/receipt and stale date explanations, preserves unanswered requirements and requires a fresh quote.
- **Four input methods:** type, microphone voice, upload image and take a photo. Original JPEG/PNG files up to 5 MiB are resized to at most 1,600 pixels, then the configured NVIDIA reader is attempted automatically with local OCR fallback. A plain privacy notice replaces provider/consent controls; only nonconfidential demo images are suitable. Whisper speech stays local; audio-file upload is removed but the microphone API remains. Output is editable and media is not stored or added to a cart automatically.
- **Accounts:** invitation-gated private registration, scrypt passwords, scoped accounts/preferences/carts/receipts, separate manager authorization, eight-hour sessions or 30-day Remember Me, persistent hashed tokens/revocation and login throttles.
- **Meal planner:** editable proposed/customer recipe quantities, explicit overlapping dietary cohorts, chosen catalog products and exact delivery transfer to Smart order. Fresh recipe acknowledgement and verified dietary evidence are required. Unknown evidence blocks unsafe confirmation.
- **Trust and saved result:** exact cart/freshness approval, atomic synthetic spending, idempotent simulated confirmation, complete item/date/approval receipt and read-only consistency verification. Retained milk Trust scenarios remain available in the shared demonstration.
- **Hosted runtime:** one Modal CPU, 1,536 MiB memory, one container/input, private catalog and SQLite state volumes; commit before mutation acknowledgement. Local Aiven TLS integration retained without widening its allowlist.

## Operating boundaries

This is a challenge simulator using restricted synthetic catalog/commercial data. Delivery/service fees are excluded. Missing claims, ambiguous packages, unsupported variable weights/deposits or unavailable delivery evidence can block a basket. Recipes need chef review; allergy safety and commercial production readiness are not certified. NVIDIA text is optional; automatic image processing is limited to nonconfidential demonstration content under the privacy notice. Broader accents/noisy kitchens/handwriting, enterprise identity and horizontal scale are outside measured coverage.
